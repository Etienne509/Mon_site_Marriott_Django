# Marriott Port-au-Prince - Projet Django

Ce projet consiste à migrer un site web statique (réalisé en HTML, CSS, Bootstrap et JavaScript) vers le framework **Django**, dans le cadre du cours de **Programmation Web 2**.

## 🛠️ Prérequis
Assurez-vous d'avoir installé sur votre machine :
- Python 3.x
- Git

## 🚀 Étapes d'installation et d'exécution

1. **Cloner le dépôt GitHub sur votre machine :**
   ```bash
   git clone [https://github.com/Etienne509/Mon_site_Marriott_Django.git](https://github.com/Etienne509/Mon_site_Marriott_Django.git)
   cd Mon_site_Marriott_Django

   Créer et activer l'environnement virtuel (venv) :

Sur Windows (PowerShell) :

Bash
python -m venv venv
venv\Scripts\Activate
Sur Mac / Linux :

Bash
python3 -m venv venv
source venv/bin/activate
Installer les dépendances (Django) :

Bash
pip install django
Lancer le serveur de développement Django :

Bash
python manage.py runserver
Accéder au site :
Ouvrez votre navigateur web et allez à l'adresse suivante :
http://127.0.0.1:8000/
